# 『腐らない森の菌糸体』全体プロット（第1〜130話）

作成：2026-10-04。初期全体設計（引継ぎ資料の付録D）を土台に、既存の第1〜16話で起きたことに合わせて組み直した。第17話以降は変更できる構想で、本文の既成事実ではない。

## 物語の核と結末

- 一行：分解者が消えて三百年あまり何も腐っていない世界に、菌類研究者がカビとして転生する。目も耳もない体で、見えない放射の正体、腐らない森の理由、世界がこうなった原因を実験で解き明かしていく。最後に彼は、自分ではない自分の子どもたち（胞子から育つ別の個体）に世界の分解を託す。
- 主題：「誰も読まない論文」と「誰が片付けるのか」。第1話の祖父の山の問い（倒れた木は誰が片付けるのか）と、第12話の「俺が死んだら、誰が俺を片付けるんだ？」に、最終話で答える。
- 結末：世界は少しずつ腐り始める。分解するのは彼の胞子から育った、彼と同じ株だが彼ではない菌たちだ。彼の論文（板と紙に黒い菌糸で書いた記録）には、人間の読み手がつく。彼自身は最後まで菌のまま、薪の山の下の森の床にいる。最終話の最後の一文は「俺が死んだら、俺の子どもたちが片付ける。」とする。
- 転生の理由は最後まで明かさない。

## 世界の真実（作者だけが知る。第16話までの描写と矛盾しないように確定させた版）

1. **右光（作中の人間の呼び名は未定。初期設計の「魔素」）**：旧文明が作った滅菌の場。電離放射線に近く、菌の壁と遺伝子を壊す。距離の二乗で弱まり、密なものと水で遮られる。
2. **滅菌塔**：地下深くに網の目状に埋められた発生源。森の床のどこにいても下から薄い右光が来るのはこのため（第10話）。塔ごとに出力の周期がある（第6章で測る）。
3. **灯石（薪の石）**：ケイ素の結晶に未知の金属を混ぜて、塔の「口」の近くに置くと右光を出すようになる。時間とともに弱まる（第16話の「古い石ほど弱い」は正しい）。防疫官の組合だけが、塔の口で石を作り直す手順を受け継いでいる。銅線の螺旋は出力を整える仕掛けだが、今の人間には由来が分からない。
4. **なぜ作ったか**：三百年あまり前、人間や動物に取りついて神経を操る菌の疫病（灰化病。冬虫夏草の仲間に近い）が広がった。旧文明は世界規模の滅菌でそれを消した。消しすぎて、分解者の菌も細菌も消えた（第12話の「境目が急」）。
5. **その結果**：倒れた木も葉も死骸も腐らない。燃える物が溜まり、数十年おきに森の火が来る（第14話の焦げた層。人間は「灰の季節」と呼ぶ）。土は痩せ、畑は育たず、旧文明は飢えで崩れた。発酵食品も失われた。
6. **今の人間**：小さな集落で暮らす。死者は焼き、灰を畑に撒く（灰撒き）。灯石を薪のカビ除けや明かりに使う。掟は「黴は灰化病の前触れ。見つけ次第、削って焼け」。焼く役目の防疫官がいる。紙は腐らないので、三百年前の記録が廃村の書庫に残っている。
7. **皮肉**：滅菌が長く続いたせいで、生き残ったのはメラニンを持つ菌だけになった。休眠している灰化病の菌もメラニンを持っていて、塔の右光ではもう止められない。今の塔は、病原菌を止めずに、ほかの生き物だけを殺し続けている（第7〜8章の核心）。
8. **主人公だけの立ち位置**：白色腐朽菌で、メラニンの鎧を持ち、分解ができる。今この世界でそれができるのは彼の株だけ。

## 章ごとのプロット

### 第1章「俺は何本あるのか」（第1〜12話）既存稿

体、右光、苦い鎧、石の柱、薪の山、削られて焼かれる、休眠細胞と胞子、下からの右光、葉の層、腐った層。山場は「三百枚分、何も腐っていない」。章末の問い：俺が死んだら誰が片付けるのか。

### 第2章「腐らない森」（第13〜25話）第13〜16話は既存稿

- 中心の問い：分解者のいない森の生態と、「どこまでが俺か」。
- 主な実験：窒素の制限、焦げた層の年代、削り方の切り分け、石の強さの比較、拍の結合、冬の時計、自分を切る実験。
- 山場：第21〜22話。体を半分に切り、どちらに「俺」が残るかを確かめる。
- 章末：薪の山の裏の壁の向こうに、紙の束（廃村の書庫）。触れた角がもう溶けている。
- 詳細は下の「第17〜25話」。

### 第3章「文字を食べる」（第26〜40話）

- 中心の問い：人間の記号は読めるか。読むことの代償。
- 舞台：薪の山が寄りかかっている廃屋の書庫。紙は三百年あまり腐らずに残っている。
- 仕組み：墨（鉄と渋の味）の線を菌糸でなぞると形が分かる。しかし溶かす仕組みは止められない（第1話）ので、読んだページは食べてしまう。読み直しができない。
- 鍵：第24話の「数を記録する板」。人間が持ち去った薪の本数と板の線の数が一致していたので、数字の形が分かっている。板の「鉤」「三本」「輪」など、持ち主ごとの印も、書庫の帳面に出てくる。
- 段階：数字 → 暦（明るさの周期の記録と、帳面の日付の並びを合わせる） → 図の多い本（菌の絵。自分の仲間を描いた線） → 「黴」「焼く」「石」などの語 → 灯石の納品台帳（石の古さと強さの関係が自分の測定と合う） → 灰化病という語。
- 代償：一冊読むごとに一冊が減る。どの本を食べるかの選択が毎回ある。
- 山場：「防疫の手引き」を、何ページ食べるかを決めてから読む。読めたのは手順の半分。
- 章末：書庫に、今の人間の足取りが来る。いつもの薪取りとは違う、重い揺れと石灰の味。

### 第4章「防疫官」（第41〜55話）

- 中心の問い：焼きに来る人間の手順と、その穴。
- 相手：防疫官（化学的な特徴で「石灰の人」と呼ぶ）。食べられたページと黒い跡を見つけ、書庫に黴がいると判断する。
- 手順と穴：石灰（第8話のシュウ酸で中和、溶けない粉が残る） → 新しい灯石の追加（強いが年とともに弱る。帯がずれる計算） → 乾燥と火（濡れた層、葉の層の深く、休眠細胞） → 炭の上の黒は見つけにくい（第15話） → 明るい時間にしか来ない（第15話の傍証が確定する）。
- 防疫官も学ぶ。削り跡を見て、薄い菌糸の通り道まで探すようになる。互いに手順を変え合う知恵比べ。
- 山場：防疫官が書庫ごと廃屋を焼く。主人公は書庫の大半を失い、読んだ内容は自分の記録の中にしか残らない。
- 章末：焼け跡に、板だけが残っている。板には新しい印が書かれ続けている。

### 第5章「発酵という交渉」（第56〜70話）

- 中心の問い：菌のやり方で意思を伝えられるか。
- 書く：板の上に、黒い菌糸で線を描く。最初は数字（前回の訪問で持ち去られた薪の本数）。見ていることを示す。黒は見つかれば削られるので、書いた次の訪問までに書き直す競争になる。
- 土：主人公が分解した葉の層の一角で、根が増え、芽が出る（第23話の伏線）。灰撒きの集落の畑の者が、その土を持ち帰る。
- 甘くする：置かれた煮た穀物を主人公の酵素が甘くする。三百年あまり失われていた発酵に近いもの。ただし主人公は自分の出す物に毒がないかを確かめる実験を先にやる（安全の確認で一話使う）。
- 集落が割れる：畑の者は土と甘い粥がほしい。防疫官は掟どおり焼きたい。主人公は板の文字の変化から割れ方を読む。誰にも崇められない。畑の者も、使える黴として扱うだけ。
- 山場：板に「焼くな」と書くか、「土」と書くか。主人公は「土」と、焼かれた時に失う量を数字で書く。
- 章末：板に、主人公の知らない形の印。人間の側から、質問が来る。

### 第6章「旧文明の消毒」（第71〜85話）

- 中心の問い：右光は誰が、何のために作ったのか。
- 読み手：畑の者が、書庫の焼け残りや集落の記録を、板に炭で書き写して持ってくる。主人公は紙を食べずに読めるようになる。人間が彼の司書になるが、目的は取引。
- 測る：体が大きくなり、薪の山・森の床・畑の土まで広がったので、下からの右光の強さを離れた場所で比べられる。向きと深さの見当がつく（第10話の続き）。出力に周期があることを、苦い枝の伸びの長期記録で見つける。
- 分かる：塔の網、灯石は塔の口で作ること、灰化病、世界規模の滅菌、消しすぎた結果。
- 山場：記録の中の、旧文明の誰かの一文。「分解する者がいなくなる危険は承知している。しかし、ほかに道はない」。主人公は、自分が前世で読んだ論文の書き手たちを思い出す。
- 章末：畑の新しい区画を掘った土の中から、主人公の知らない菌の味。

### 第7章「眠る病原体」（第86〜100話）

- 中心の問い：病原菌はまだいるのか。自分はそれと何が違うのか。
- 発見：第12話の「俺以外の誰かが今食べている味がしたら倒れる」が、最悪の形で満たされる。旧い墓地の、粘土と石で塞がれた場所で眠っていた灰化病の菌。メラニンを持ち、右光に強い。
- 違い：病原菌は生きた体の神経を食べる。主人公は死んだものしか食べない。ただし菌は菌を食べられる（自分の死骸を溶かしてきた経験）。病原菌の壁を溶かす実験。
- 防疫官：焼く手順はメラニンの菌に効きが悪い。防疫官が板に書いて、主人公から病原菌の場所の情報を得る。味方にはならない。互いに相手を使う。
- 山場：集落の家畜に灰化病が出る。主人公は病原菌を食べて封じ込めるが、体の大部分を失う。
- 章末：塔の右光では、もう病原菌を止められない、という測定結果。

### 第8章「世界を分解し直す」（第101〜130話）

- 中心の問い：塔の網をどうするか。
- 選択肢：塔を残す（病原菌は止まらず、ほかの生き物は戻らない）／塔を止める（主人公と病原菌しか残っていない世界に、何が起きるか分からない）／第三の道。
- 第三の道：塔の出力の周期と網の穴を使って、場所と時期を区切って右光を下げる。そこへ、病原菌を食べ、木と葉を分解する主人公の子どもたちを放つ。子どもたちは主人公と同じ株で、苦い鎧を持つ。ただし、つながっていない子どもたちは「俺」ではない（第21〜22話の結論）。
- 代償：自分ではないものに世界を託す。体の大半を胞子に変えるので、つながった「俺」は小さくなる。
- 人間：畑の者は塔の口で石を作る手順を変える。防疫官は最後まで反対するが、主人公の記録を写して組合の書庫に入れる。
- 山場：最初の腐る季節。森の床で、三百年あまりぶりに誰かの食べ残しの味が増えていく。主人公の子どもたちの味だ。
- 最終話：主人公の論文の最後の一行。森の火の間隔が延び始めたという測定。祖父の山の問いに答える一文で終わる。

### 第2章の山場の結論（第20〜22話で実際に出したもの）

1. 自分で空の管を作って切り離した区画は、先っぽ十本の小ささでも、自分の拍を打つ（第20話）。小さいほど拍はばらつき、本体と揃いやすい。大きいほど揃いにくく、揃えるには太い通り道が要る（第17・20話）。一度揃えば、細い道でも揃ったまま（第17話）。眠っている丸い部屋は拍を打たない（第17話）。
2. 切り口の両側は、相手が生きているあいだ、薄い苦甘い味を出して呼び合い、互いに向かって伸びる。相手が死ぬと味が消え、伸びるのをやめる（第20話）。第16話の「探していたのか」は、「呼び合う仕組みがある」に置き換わった。
3. 半分に切ると、主人公の体験は、拍の生まれる場所を含む側（山の中、小さいほう）に続いた（第21話）。一回きりなので一般化しない。
4. つながり直すと、二つの拍は大きさで重みをつけた間の速さで揃う（第22話。6800と7500が7200に）。合流後、拍の生まれる場所は葉の層へ移ったが、主人公の体験には何の変化もなかった。だから「俺は拍の生まれる場所に宿る」とは言えなくなった（第22話）。
5. 切り離された側は、そのあいだも食べ、眠る部屋を作り、呼び合い、探っていた。そこで何かが感じていたのかは、内側からは確かめられない。主人公は「今ここで拍が揃っていて、ここに書いている俺の続きにつながっている範囲を、俺と呼ぶ。切り離されたもの・胞子から育つものは身内で、俺ではない」と決めた（第22話）。

## 守る決まり（全話共通）

- 単位：夜露・室・菌糸日・線量計・拍。現実の単位は前世の当て推量と断る時だけ。
- 感覚：味、押される・揺れる手応え、温度、青い光（弱い〜強い）、体内の電気の合図。見る・聞く・言葉の理解・名前の認識はできない。文字は「形」としてなぞって覚える。発音は分からない。
- 人間は化学的な特徴か、記号の形で呼ぶ（「石灰の人」「鉤の印」）。
- 本文では「第〜話で」「前回はそこで終わった」のような話数で指すメタな言い方を使わない。過去の出来事は「焼かれた時」「上の薪が持っていかれた時」のように、作中の出来事で指す。
- 主人公は菌のまま。崇められない。都合よくルールを曲げない。各話に失敗と代償。締めは次の実験につながる異変か具体的な問い。
