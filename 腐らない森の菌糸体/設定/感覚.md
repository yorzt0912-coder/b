# 感覚

| できる | できない |
|---|---|
| 味（化学物質の濃さと方向） | 見る（色・姿） |
| 押される・揺れる手応え | 聞く |
| 温度 | 言葉を理解する |
| 青い光（弱い光から、表面に出れば強い明るさまで） | 人や物の名前を知る |
| 体の中の電気の合図（[[拍と俺の範囲\|拍]]） | |

- 「黒い」「白い」は前世の知識による呼び方で、今の体で色を確かめたわけではない
- 文字は、線を菌糸でなぞって形として覚える。発音は分からない（[[第24話 誰が数えているのか|第24話]]）
