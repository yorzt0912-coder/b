# 物差し

| 名前 | 意味 | 作った話 |
|---|---|---|
| 夜露 | 時間。湿ってから次に湿るまで。霜の季節からは「暗くなってから次に暗くなるまで」 | [[第02話 右から来る何か|第2話]]・[[第18話 夜露が来ない夜は何と数えるか|第18話]] |
| 菌糸日 | 長さの目安。苦くない先っぽが一夜露で伸びる長さ。約60室 | [[第02話 右から来る何か|第2話]] |
| 室 | 長さ。菌糸の小部屋一つ分。伸びる速さに左右されない | [[第03話 黒い菌糸はなぜ死なないか|第3話]] |
| 先っぽの数 | 体の大きさ。最初の千と少しを1倍とする | [[第01話 俺は何本あるのか|第1話]] |
| 線量計 | 右光の強さ。苦くない先っぽが8夜露で死ぬ強さを1、4夜露なら2 | [[第04話 どこまで近づけるのか|第4話]] |
| 拍 | 体の中を通る電気の合図一回分。一夜露に八千あまり（冬は6600ほど）。熱で速く、寒さで遅くなる | [[第07話 揺れは何を運んでいるのか|第7話]] |
| 明るい時間の割合 | 季節の物差し。拍の数ではなく割合で数える | [[第12話 最後に腐ったのはいつか|第12話]] |

- 苦い鎧の枝の伸び：右光の弱い所で37室/夜露、食べ頃の帯で140室/夜露
- 現実の単位（センチ・ミリ・秒）は使わない。使うのは「前世の感覚の当て推量」と断る時だけ
