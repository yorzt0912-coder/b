# 外の何か

主人公には姿が分からない、外から来て薪の山を揺らす何か。人間かどうかは作中では断定していない。

- 明るい時間にだけ来る。冬はほぼ毎夜露（[[第15話 向こうは何を見て削るのか|第15話]]・[[第18話 夜露が来ない夜は何と数えるか|第18話]]）
- 来る時は一拍に15〜16回揺れ、重い物を持って帰る時は12〜13回（[[第07話 揺れは何を運んでいるのか|第7話]]）
- 鉄の味のするまっすぐな縁で、表面の黒い菌糸を削る。目で見ているらしい（[[第07話 揺れは何を運んでいるのか|第7話]]・[[第15話 向こうは何を見て削るのか|第15話]]）
- 塩気・脂・酸の味のする、ぬるく柔らかいもので触れる（[[第07話 揺れは何を運んでいるのか|第7話]]）
- 火をつけ、水をかける（[[第08話 どこまで逃げれば焼けないか|第8話]]）。錐で新しい石を埋める（[[第16話 切られた側は何をしていたか|第16話]]）
- 板に、誰が何本持っていったかを記録する（[[第24話 誰が数えているのか|第24話]]）
